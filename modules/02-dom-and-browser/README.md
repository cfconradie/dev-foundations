# Module 02 — DOM and browser

**Goal:** make JS actually touch a page. Selecting/modifying elements, events, forms, fetch,
storage — the bridge between "I know JS" and "I can build an interactive page."

**Prerequisite:** module 01 (functions, arrays, async/await).

**Done when:** you can build a small interactive feature (a live search, a form with validation)
without a framework, and you understand what a framework like Vue/React is actually doing for you
underneath.
