# Module 06 — Vue rebuild

**Goal:** learn Vue by rebuilding the capstone in it. You already know the underlying JS/TS
concepts (modules 01-03) — this module is "how does Vue structure the concepts you already know,"
not the language again.

**Prerequisite:** modules 01-05 (especially the shipped capstone).

**Done when:** the capstone is rebuilt in Vue with equivalent functionality, and you can explain
what Vue is doing for you at each step that you were doing manually in module 02 (DOM
updates, event binding, etc.).
