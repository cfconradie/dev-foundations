# Module 00.5 — Project kickoff

**Goal:** turn the course from a pile of disconnected exercises into one running project. By the
end of this short module you'll have a written spec for the pricing/quote calculator in
`PROJECT.md`, a git workflow you'll use for every task from here on, and an understanding of how
the integration backlog keeps purely conceptual tasks (later, in DS&A and system design) honest
about tying back into real work.

**Prerequisite:** module 00 (enough HTML/CSS to have a page to eventually build the project's
landing page in).

**Done when:** `PROJECT.md` reflects your own read on the project (not just a copy of the seed
spec), you've made your first task-branch commit, and you can explain what `INTEGRATION-BACKLOG.md`
is for without re-reading it.
