# Module 01 — JS fundamentals

**Goal:** this is the real depth work of the whole course. Variables, types, control flow,
functions, scope, closures, async — the underlying mechanisms, not memorized syntax. Everything
after this module (TypeScript, Node, Vue, React) is these same concepts wearing a different
outfit, so don't rush this one.

**Prerequisite:** module 00 (enough HTML to have a page to run scripts in).

**Done when:** you can write a script from a blank file without looking up basic syntax, and you
can explain *why* something works, not just that it does.
