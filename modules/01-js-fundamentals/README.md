# Module 01 — JS fundamentals

**Goal:** this is the real depth work of the whole course. Variables, types, control flow,
functions, scope, closures, prototypes, classes, the event loop, async — the underlying
mechanisms, not memorized syntax. Everything after this module (TypeScript, Node, Vue, React) is
these same concepts wearing a different outfit, so don't rush this one. This is also where the
project's real pricing logic gets built for the first time — most tasks from here on work against
real `PricingRule`/`QuoteRequest` data from `PROJECT.md`, not throwaway examples.

**Prerequisite:** module 00.5 (the project spec exists, and the git workflow is running).

**Done when:** you can write a script from a blank file without looking up basic syntax, you can
explain *why* something works (not just that it does), and the project has a real, tested-by-hand
pricing engine (task 028) that later modules will build on.

**Task order note:** this module was expanded during the course redesign — prototypes, classes,
`call`/`apply`/`bind`, strict mode, the event loop, `Object.freeze`/immutability, Map/Set, and
recursion (promoted from an optional stretch) are now required tasks, not gaps. See `ROADMAP.md`
for the reasoning.
