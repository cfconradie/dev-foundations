# Task 001 — Variables and types

**Concept:** `let`/`const`/`var` differ in scope and mutability, and JS has a small set of
primitive types plus objects — this is the vocabulary everything else is built from.

**Step 1 — build it yourself, no AI:** in a `.js` file run with `node`, declare variables of each
primitive type (string, number, boolean, null, undefined), log `typeof` each one, and try
reassigning a `const` to see the error.

**Done when (step 1):** you can explain the difference between `let` and `const`, and why
`typeof null` prints `"object"` (a known JS quirk).

**Step 2 — AI review pass:** ask the AI to explain any typeof result that surprised you.

**Stretch (optional):** look up what a Symbol and a BigInt are for.
