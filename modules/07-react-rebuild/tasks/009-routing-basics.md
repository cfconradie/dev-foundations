# Task 009 — Routing basics

**Concept:** React Router serves the same job as Vue Router (module 06 task 008) — URL-to-
component mapping without full page reloads — with a different (component-based, `<Route>`)
API.

**Step 1 — build it yourself, no AI:** install React Router, set up the same two routes (`/` for
the calculator, `/admin` for the quote list) with navigation, matching the Vue Router setup you
already built.

**Done when (step 1):** navigation works without page reloads, and back/forward buttons behave
correctly, same as the Vue version.

**Step 2 — AI review pass:** ask the AI to point out any structural difference between React
Router's and Vue Router's route-definition style worth knowing.

**Stretch (optional):** add a route param (`/admin/quotes/:id`) matching Vue's stretch task.
