# Task 011 — Capstone rebuilt in React (module capstone, course capstone)

**Concept:** the final rebuild — the same app, third time, now in React, reusing the same
unchanged backend. By this point you should be able to say exactly which parts of building an app
are "the framework" and which parts are universal software engineering (data modeling, API
design, validation, error handling) that would be the same in any framework or none at all.

**Step 1 — build it yourself, no AI:** rebuild the full capstone frontend in React: the
calculator with live pricing, the quote form (controlled inputs + validation), routing between
calculator and admin, and the admin quote list with status updates.

**Done when (step 1):** every item in module 05's Definition of Done still holds, now
React-powered, and you can write a short comparison (in PROGRESS.md) of the same app across all
three versions: vanilla, Vue, React — what got easier, what got more verbose, what stayed
identical because it was never about the framework.

**Step 2 — AI review pass:** paste the React app's structure and ask for a final review: hook
usage correctness, unnecessary re-renders, component splitting, and anything that looks like it
was written "the Vue way" instead of idiomatic React. Log the best finding — this is the last
review pass of the whole course.

**Stretch (optional):** deploy this React version alongside (or replacing) the vanilla capstone,
and link both from your portfolio to show the same problem solved three ways.
