# Module 07 — React rebuild

**Goal:** learn React by rebuilding the capstone again. Most of the concepts (components, props,
one-way data flow, hooks-as-closures) transfer directly from Vue — this module is mostly "same
ideas, different API," with a few genuinely new mental models (JSX, the dependency array).

**Prerequisite:** module 06 (Vue rebuild) — this module leans on that comparison constantly.

**Done when:** the capstone is rebuilt in React with equivalent functionality, and for every
React concept you can say what its Vue equivalent was.
