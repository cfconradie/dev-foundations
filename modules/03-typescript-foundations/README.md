# Module 03 — TypeScript foundations

**Goal:** add types to what you already know in JS. TypeScript doesn't introduce new logic — it
lets you describe the *shape* of the data you're already working with, and catches a whole class
of bugs before you run the code.

**Prerequisite:** module 01 (this module is JS + a type layer, not new concepts).

**Done when:** you can convert a plain JS file to TypeScript and fix every error the compiler
raises, understanding *why* each one is a real bug it just caught.
