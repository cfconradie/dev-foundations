# Task 003 — Tailwind setup

**Concept:** Tailwind classes are just pre-written CSS rules with short names (`p-4` = padding:
1rem) — it's not a new language, it's CSS with a naming convention, which is why module 002
matters before this one.

**Step 1 — build it yourself, no AI:** install Tailwind into a small static project (Vite +
Tailwind is fine) following the official Tailwind docs (not an AI-generated summary of them), and
get a single styled `<h1>` rendering with a Tailwind class.

**Done when (step 1):** editing a Tailwind class in the HTML visibly changes the rendered page,
and you can say what `text-2xl font-bold text-blue-600` does without looking it up.

**Step 2 — AI review pass:** ask the AI to check your Tailwind config/build setup for anything
off (e.g. content paths not scanning your files, so classes get purged).

**Stretch (optional):** look at the generated CSS output and find the actual rule for one class
you used.
