# Task 006 — Build a static page (module capstone)

**Concept:** combine everything in this module into one real artifact — this is the "can you
actually do it unaided" checkpoint before moving into JavaScript.

**Step 1 — build it yourself, no AI:** build a one-page personal landing page (header/nav, a
hero section, a 3-item feature/skills grid, a footer) using semantic HTML + Tailwind only. No JS
yet.

**Done when (step 1):** it's responsive (works from phone-width to desktop-width) and every
section uses a semantic tag you'd defend in a review.

**Step 2 — AI review pass:** paste the full HTML and ask for a structural + accessibility review
(not a redesign) — semantic tag misuse, missing alt text, color-contrast concerns.

**Stretch (optional):** add a Tailwind-only mobile nav toggle using the `hidden`/`peer` pattern
(no JS) to see how far pure CSS can go before you actually need JavaScript — which is where
module 01 picks up.
