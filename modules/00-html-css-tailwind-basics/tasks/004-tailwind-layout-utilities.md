# Task 004 — Tailwind layout utilities

**Concept:** rebuilding task 002's flex row using only Tailwind classes shows you the direct
mapping from raw CSS to utility class — the goal is that you never feel like Tailwind is a black
box.

**Step 1 — build it yourself, no AI:** rebuild the 3-card row from task 002 using only Tailwind
utility classes (`flex`, `gap-4`, `p-4`, `border`, `rounded`, `w-1/3` or `flex-1`) — zero custom
CSS.

**Done when (step 1):** the rebuilt version looks the same as your hand-written CSS version from
task 002, and for each class you can name the raw CSS property it maps to.

**Step 2 — AI review pass:** ask which utility classes are considered idiomatic vs which ones you
used that have a more conventional Tailwind equivalent.

**Stretch (optional):** add `grid` + `grid-cols-3` as an alternative layout and compare to flex.
