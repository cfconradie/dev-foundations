# Module 00 — HTML/CSS/Tailwind basics

**Goal:** just enough HTML/CSS to read and structure a page, then straight into Tailwind utility
classes. This module is deliberately short — HTML/CSS depth is not the point of this course.

**Prerequisite:** none.

**Done when:** you can look at a page's HTML and know what each tag is for, and you can style a
layout using only Tailwind classes (no hand-written CSS file).
