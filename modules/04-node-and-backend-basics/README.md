# Module 04 — Node and backend basics

**Goal:** JS on the server. The Node runtime, npm, a raw HTTP server, then Express, middleware,
env vars, and a real database connection — everything the capstone's backend needs.

**Prerequisite:** modules 01-03 (async/await, modules, and TypeScript are all used here).

**Done when:** you can build a small REST API from scratch, explain what each middleware does,
and connect it to a real database — without copy-pasting a boilerplate you don't understand.
