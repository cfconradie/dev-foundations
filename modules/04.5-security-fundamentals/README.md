# Module 04.5 — Security fundamentals

**Goal:** security as a standing discipline, not two Step-2 asides. Auth, XSS, CSRF, and an OWASP
Top 10 walkthrough — all attacking and hardening the project's real endpoints, because a backend
that's never had a security pass isn't actually finished.

**Done when:** you can point at a specific line in the project and explain a specific attack it's
vulnerable to (or why it isn't), for every category this module covers — not recite OWASP category
names.
